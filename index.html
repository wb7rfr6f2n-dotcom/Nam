📖 Hướng dẫn sử dụng

  • 1. Lấy file bundle: Dùng ứng dụng quản lý file (ZArchiver, v.v.) truy cập vào thư mục game: Android/data/com.dts.freefireth/files/contentcache/Compulsory/android/gameassetbundles/
  • 2. Chọn file: Nhấp vào ô chọn file ở trên và tải file bundle lên.
  • 3. Chỉnh sửa: Bật/tắt các tính năng theo ý muốn và chọn "Tạo File".
  • 4. Thay thế: Tải file sau khi sửa về và chép đè vào vị trí cũ trong game.
